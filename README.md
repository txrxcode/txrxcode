### Hey, I'm Rohit 👋

I'm an **AI engineer and site reliability engineer in Toronto, Canada**. I build and run the plumbing that makes AI features dependable: serving LLMs, wiring AI agents into real systems, and making sure someone gets paged before users notice.

My default question for any repetitive task: **can I automate that?**

- 🧠 **AI engineering**: LLM apps, RAG, evals, and agents with guardrails
- 🛠️ **Reliability**: SLOs, observability (Prometheus, Grafana, Loki), incident response, Kubernetes
- 🏠 **Home lab**: self-hosted LLMs, GPUs and networks I'm allowed to break
- ✍️ **Writing**: I explain systems as tiny isometric cities at [txrxcode.com](https://txrxcode.com)
